After years of meaning to do it, I finally rewrote the site. The old Jekyll setup worked fine since I haven't updated it after the first post. However, I also used a similar setup for the [[Aphid EV]] project log where I found it lacking, which is why I developed [[Aphid]]. Since I have my own static site generator I might as well migrate this site to it as a form of dogfooding — especially since it is much smaller and easier to migrate than my project log.

# Why aphid

There's a longer post on why I developed [[Aphid]] on the project site, but in short I wanted a simple, opinionated static site generator with support for both a blog and a wiki. Modern agentic coding tools make it so easy to create exactly the software you need.

# What changed

- Engine: Jekyll → aphid
- Hosting: still GitHub Pages
- URL: unchanged
- Theme: completely new
- Wiki section: new *(not sure what to use it for on this site yet)*

# What's next

Not sure to be honest. I haven't written anything here for years, and I don't think that will change.
