I'm LHelge — software engineer in Sweden by day, hardware tinkerer by evening, EV builder on the weekends.

By day I write Rust and TypeScript for a sensor company. By night I solder things to other things and document the lessons here so future-me doesn't have to learn them again.

# What I'm working on

Currently: an 11 kW home charger using OCPP 1.6, a reflow oven controller for hobby PCBs, and an ongoing project to make my garage's solar inverter talk to Home Assistant in a way that doesn't lie.
